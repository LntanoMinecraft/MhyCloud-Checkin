# 云签助手 · MhyCloud-Checkin

**采用 Material Design 3 Expressive 设计的《云·原神》与《云·绝区零》Android 自动签到助手**






*本项目代码由 Google AI Studio 中的 **Gemini 4 Hydrogen** 编写生成*

---

## 项目简介

**云签助手（MhyCloud-Checkin）** 是一款专为《云·原神》与《云·绝区零》打造的轻量级本地自动签到工具。你无需每天手动打开动辄上百 MB 的云游戏客户端，App 会在后台自动完成每日签到、统计剩余免费时长、推送执行汇报，并在免费时长达到上限时自动暂停调度，兼顾省心与安全。

---

## 核心特性

* **双游戏多账号支持**
  同时支持《云·原神》与《云·绝区零》，支持多账号独立备注、独立开关与独立状态追踪。
* **Material Design 3 Expressive 视觉体验**
  * 采用 **MD3 Expressive 悬浮式底部胶囊导航栏**、大圆角状态卡片与弹簧物理动效。
  * 原生支持 **Android 12+ 系统动态取色（Dynamic Color / Monet）** 以及跟随系统的**深浅色自动切换**（也可在设置内手动锁定）。
* **Root / 基础双模式架构**
  * **Root 模式**：一键扫描本机已安装的官方客户端，安全读取本地配置与会话，无需手动抓包，并支持自动写入系统 Doze 电池白名单。
  * **基础模式（无需 Root / Shizuku）**：《云·原神》内置隔离 `WebView` 登录自动捕获；《云·绝区零》支持剪贴板一键识别 `cURL` 与 HTTP 请求头，并内置双端（手机端 / 电脑端）新手导入指南。
* **智能调度与通知闭环**
  * 结合 `AlarmManager` 精确闹钟、`WorkManager` 加急任务、开机恢复与 12 小时兜底巡检，搭配 `0 ~ 30` 分钟随机时间抖动防风控。
  * 每日任务完成后推送**结果汇总通知**；当免费时长达到上限（默认 `600` 分钟）或凭证彻底失效时推送高优提醒并自动暂停/熔断。
* **本地硬件级加密与隐私保护**
  * 所有账号凭证通过 **Android Keystore + `EncryptedSharedPreferences`（AES256-GCM）** 加密保存。
  * 剪贴板导入后自动清空残留，运行日志默认对 UID 与 Token 中间打码脱敏。

## 模式对比

| 特性 | 基础模式（免 Root） | Root 模式 |
| :--- | :--- | :--- |
| **云·原神凭证获取** | 内置 `WebView` 登录自动捕获 | 一键扫描官方客户端本地配置 |
| **云·绝区零凭证获取** | 剪贴板一键解析 `cURL` / 请求头 | 一键扫描官方客户端本地配置 |
| **后台防杀策略** | `AlarmManager` + `WorkManager` 加急 + 电池白名单引导 | 自动加入系统 Doze 白名单 + 定时唤醒 |
| **失效自动续期** | 云·原神支持静默 `WebView` 刷新 | 自动重读官方客户端最新会话补签 |

## 快速上手

1. **下载与安装**：前往本仓库 [Releases](https://www.google.com/search?q=https://github.com/LntanoMinecraft/MhyCloud-Checkin/releases) 页面下载最新安装包并安装（最低支持 Android 8.0）。
2. **完成权限自检**：首次打开进入 **设置 → 系统权限自检**，授予**通知权限**、将电池优化设为**无限制**（基础模式建议同时开启**精确闹钟权限**）。
3. **导入游戏账号**：点击首页右上角 **添加**，按提示选择 `Root 模式` 一键扫描，或按 `基础模式` 引导完成登录/粘贴导入。
4. **开启每日自动签到**：设定你习惯的每日基准时间与随机抖动范围即可；当免费时长满 600 分钟时会自动暂停，消耗时长后可随时在首页卡片一键恢复。

## 安全设计说明

* **防注入隔离**：Root 读取仅限硬编码的白名单包名（`com.miHoYo.cloudgames.ys`、`com.miHoYo.cloudgames.Nap`）与固定配置文件路径，绝不拼接外部输入。
* **WebView 沙盒**：内置登录页仅放行米哈游官方域名，禁用本地文件与内容访问，全局禁止明文 HTTP 流量。
* **来源指纹绑定**：严格区分安卓端与网页端设备头信息，避免跨端参数混搭触发账号风控。
