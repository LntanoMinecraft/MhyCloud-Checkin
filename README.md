# 云签助手（MhyCloud-Checkin）

一款采用 **Material Design 3 Expressive** 设计的 Android 云游戏自动签到工具，帮助玩家轻松完成每日自动签到。

## 核心功能

- **多游戏支持**：支持《云·原神》与《云·绝区零》自动签到。
- **现代界面设计**：基于 Material Design 3 Expressive 打造，支持动态取色（Dynamic Color）。
- **基础 / Root 双模式**：同时提供基础模式与 Root 模式，适配不同设备使用需求。
- **本地加密存储**：凭证与相关数据采用本地加密保存，保障隐私与安全。
- **定时保活与通知**：支持每日定时自动执行签到，并提供签到结果通知提醒。
- **时长上限自动暂停**：当免费时长达到上限时自动暂停签到任务，避免无效运行。
