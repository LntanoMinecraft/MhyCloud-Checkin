## 一、 颜色与对比度修复规范（必改）

目前在开启系统动态取色的深色模式下，底部“贴心提醒”卡片存在背景与文字颜色不配对、对比度过低的问题。请严格按以下 **MD3 成对色彩 Token** 重构本页所有卡片的颜色：

1. **普通步骤卡片**：
   * `containerColor = MaterialTheme.colorScheme.surfaceContainerLow`

   * 小标签/步骤副标题：`MaterialTheme.colorScheme.primary`
   * 标题：`MaterialTheme.colorScheme.onSurface`
   * 正文：`MaterialTheme.colorScheme.onSurfaceVariant`

   * `containerColor = MaterialTheme.colorScheme.tertiaryContainer`
   * 内部所有图标、标题、正文与切换按钮文字统一使用 `MaterialTheme.colorScheme.onTertiaryContainer`（正文可用 `.copy(alpha = 0.88f)`），确保任何动态取色方案下清晰可读。
3. **底部“贴心提醒”卡片（重点修复）**：
   * `containerColor = MaterialTheme.colorScheme.secondaryContainer`
   * **禁止使用 `onSurfaceVariant` 或任何固定色值**：卡片内所有图标、主标题“贴心提醒”、每条小标题统一使用 **`MaterialTheme.colorScheme.onSecondaryContainer`**，每条说明正文使用 **`MaterialTheme.colorScheme.onSecondaryContainer.copy(alpha = 0.85f)`**。
4. **顶部与底部安全留白**：
   * 使用 `Scaffold` 配合 `TopAppBar`（带返回箭头）与 `navigationBarsPadding()`，列表底部保留 `24.dp` 间距，确保全面屏手势条不遮挡底部卡片。

### 底部通用“贴心提醒”卡片（两个 Tab 下方均固定展示）

* **不用自己翻找 Token**：复制出来的请求头或 `cURL` 文本很长是正常的，您不需要自己去里面挑字符，整段复制过来软件会自动识别。
* **导入后自动清空剪贴板**：识别并保存成功后，软件会立即清空手机剪贴板，防止其他后台应用读取您的登录凭证。
* **满 600 分钟自动暂停**：当检测到免费时长达到 600 分钟上限时，软件会自动推送提醒并暂停签到，消耗时长后可在首页卡片一键恢复。
* **一次导入长期有效**：只要不修改账号密码或在其他客户端顶掉登录态，通常只需配置这一次，后续每天都会自动签到。
